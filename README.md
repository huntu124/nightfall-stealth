NIGHTFALL is an original top-down stealth game built with plain ES modules and the 2D canvas — no libraries, no network requests. Sneak through three hand-built sectors (Storehouse, Courtyard, Vault Wing), read the guards' rotating vision cones, hide behind crates, sneak with SHIFT to stay silent, and reach the green EXIT unseen. A suspicion meter fills while a guard watches you; fill it and you are caught.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: WASD/arrows move, SHIFT sneak, R restart the sector, N next sector.
